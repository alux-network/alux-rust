# alux-sdk-macros

This crate contains the procedural macro implementations exported by `alux-sdk`.

For what a trait algebra is for, read [First-order programs](https://alux-network.github.io/alux-programming/rust-dd/first-order-programs.html) and [Defunctionalization](https://alux-network.github.io/alux-programming/concepts/defunctionalization.html) in the ALUX programming guidelines.

Applications should depend on [`alux-sdk`](https://docs.rs/alux-sdk), which is the reference library
for documentation and executable usage examples:

See the [`trait_algebra` documentation](https://docs.rs/alux-sdk/latest/alux_sdk/macro.trait_algebra.html)
for usage.
