# 📫 Reporting a Security Vulnerability

We take security very seriously. If you discover a potential security vulnerability in this project, **please do not create a public issue.**

Instead, report it **privately and responsibly** by sending an email to:

**✉️ [security@alux.network](mailto:security@alux.network)**

## 🛡️ Responsible Disclosure Guidelines

* Please include a detailed description of the vulnerability.
* Include steps to reproduce if applicable.
* Allow us a reasonable amount of time to investigate and address the issue before disclosing it publicly.

## 🙏 Thank You

We appreciate your efforts to help make this project more secure and thank you for following responsible disclosure practices.
